# User Guide

1. Start MySQL, run migrations, and seed demo accounts.
2. Log in as the patient and review profile, records, requests, and permissions.
3. Log in as the doctor and search by Health ID `MCH-2026-000001`.
4. Request access, then approve it from the patient dashboard.
5. Create prescriptions or upload reports after consent is active.
6. Configure Sepolia to anchor real proof transactions.
