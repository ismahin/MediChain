# User Guide

1. Start MySQL and run migrations. Enable demo mode and seed only when demo fixtures are wanted.
2. Log in as the patient and review profile, records, requests, and permissions.
3. Log in as the doctor and search using the patient's exact full name, email, or generated Health ID.
4. Choose the required consent categories, enter the clinical reason and duration, then approve the request from the patient dashboard.
5. Create prescriptions or upload reports after consent is active.
6. Configure an EVM network and authorize provider wallets to anchor proof transactions.
